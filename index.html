COBOL and JCL batch processing on z/OS

Four months of mainframe programming in the batch-processing style that banks and insurers still use to run back-office systems. I wrote the COBOL programs and the JCL (job control language) that runs them, working through a remote 3270 terminal session on IBM z/OS.

  • Wrote JCL to submit and run the programs as batch jobs
  • Read records from files, including VSAM key-sequenced datasets (KSDS) where each record is found by its key
  • Built formatted reports from the records the programs read

COBOL is strict about record layouts and data definitions, and working through it for four months made me methodical about both.
